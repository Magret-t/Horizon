# STEM and language learning profile

Use this profile for educational content about science, technology, engineering, mathematics, and language learning (especially English and IELTS preparation).

Typical items include explainers of scientific concepts, university-level STEM topics, technology overviews, learning methods and resources, IELTS tips, and English learning materials with clear educational value.

Do not use this profile for content whose primary value is breaking industry news, consumer product reviews, academic papers without accessible summaries, or promotional material.
